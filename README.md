Space Invaders–Style Game in Python
I built a Space Invaders–style arcade game using Python and Pygame. The player moves left and right with the arrow keys and presses Space to shoot. Six enemies move across the screen and drop down when they reach an edge. Hitting an enemy earns one point and respawns it near the top. An obstacle can block shots.

At 50 points, a boss appears. It moves side to side and fires back. The player needs 15 hits to defeat it and earns 15 bonus points for doing so. The game displays Game Over if an enemy gets too close to the bottom or a boss projectile hits the player.

This project gave me practice building a game loop, handling keyboard input, drawing sprites, detecting collisions, and tracking the score and boss health.
